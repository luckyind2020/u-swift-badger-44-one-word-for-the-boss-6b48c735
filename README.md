One word for the boss: **Pingasaurus** — the boss who pings you about everything, at all hours, in every channel, like a dinosaur that never learned the office went home. The entry is the word itself; `main.py` just reads it from `entry.txt`, checks it is a single word of at most 30 characters, and prints it.

## Run it

```sh
python3 main.py
```
